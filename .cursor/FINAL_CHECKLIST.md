- [ ] App icon set complete; no white/upscaled/clipped artifacts
- [ ] Launch screen shows no jarring white flash before the splash video

### 8. Loading / splash screen
- [ ] Background video plays (portrait AND landscape); bar advances with
      real boot time; total boot on normal Wi-Fi < 10 s
- [ ] Rotation mid-splash does not restart the video

### 9. Push permission screen (FeatherInvitation)

- [ ] `af_status: "Organic"` → native game; no gray content leaks

### 11. User-Agent (`gray_user_agent.mdc`)

      iOS / Safari version from `device_info_plus`), bumped from prev project
- [ ] Does NOT contain `Dart`, `Flutter`, `CFNetwork`, `Darwin`, `WebView`,
      or any package/SDK identifier
- [ ] Same UA on the HTTP client AND the WebView (`setUserAgent`)
- [ ] **Slot game?** UA ends with `appid/<bundleId> appname/<AppName>`;
      **crash game?** no suffix — decision documented as a code comment
- [ ] If the theme was ambiguous, the user was asked before generation

### 12. WebView within Safe Area (`cold_start_push_viewport.mdc`, `custom_screens.md`)
- [ ] Portrait: WebView not under the notch / Dynamic Island
- [ ] Landscape: side cutout respected on BOTH long edges (rotate 180°)
- [ ] Bottom reaches the screen edge; home-indicator inset not doubled
- [ ] Cold-start push tap → WebView NOT stretched (4-layer fix applied)

### 13. Screen rotation
- [ ] Auto-rotate works on loading + no-signal + push-invite + WebView
- [ ] Only the game path re-locks orientation if the game requires it

### 14. Back navigation (WebView)
- [ ] Back → WebView goes one page back
- [ ] On the first page, back does NOTHING (does not close the WebView)

### 15. Too-many-redirects recovery
- [ ] Redirect-loop → up to 3 automatic retries with the last URL; never
      an `ERR_TOO_MANY_REDIRECTS` / `-1007` blank page
- [ ] `-999 NSURLErrorCancelled` is ignored (not routed to No-Signal)

### 16. JavaScript + WebView features
- [ ] JavaScript unrestricted; OAuth / payment pop-ups render
- [ ] Cookies + sessions persist across reloads and app relaunch
- [ ] Inline autoplay video plays without tap-to-start
- [ ] DRM / protected media plays (permission request granted)

### 18. File upload

      gallery); no app-wide filesystem permission dialog; upload succeeds

### 19. Keyboard does not cover inputs

### 20. Push notifications **[iOS]**
